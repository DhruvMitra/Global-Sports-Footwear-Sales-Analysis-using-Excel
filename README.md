# Global Sports Footwear Sales Analysis


    Project Overview

This project analyzes global sports footwear sales data from 2018 to 2026 using Microsoft Excel.
The goal of this project is to identify key sales trends, customer behavior, and business insights through data cleaning, pivot tables, and an interactive Excel dashboard.


    Dataset

The dataset contains detailed information about global sports footwear sales, including:

Order Date

Brand

Product Model

Category

Gender

Size

Color

Base Price

Discount Percentage

Final Price

Units Sold

Revenue

Sales Channel

Payment Method

Country

Customer Income Level

Customer Rating

    Objectives of the Analysis

The project aims to answer important business questions such as:

Which brand generates the highest revenue?

Which countries have the highest sales?

Which product categories sell the most?


Which sales channel performs better (Online vs Store)?

Which customer income group spends the most?

What are the  yearly sales trends?

Which payment methods are most commonly used?

    Data Cleaning Process

Before analysis, the dataset was cleaned using Excel:

Removed duplicate records

Checked and handled missing values

Standardized column formats

Converted dates into proper date format

Verified numeric columns (price, revenue, units sold)

Created additional calculated fields where necessary

    Key Analysis Performed
1. Sales Trend Analysis

Analyzed yearly revenue trends to understand sales growth over time.

2. Brand Performance

Compared revenue generated by different footwear brands to identify top performers.

3. Product Category Analysis

Identified which footwear categories sell the most units.

4. Country-wise Sales Analysis

Examined sales distribution across different countries.

5. Sales Channel Analysis

Compared performance between Online and Store sales channels.

6. Customer Income Level Insights

Analyzed purchasing behavior across different income groups.


7. Payment Method Analysis

Identified the most commonly used payment methods by customers.
